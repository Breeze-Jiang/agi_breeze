AI公司已经进入新的阶段，过去大家拼的是模型能力，谁参数更强，谁上下文更长（一次可以给大模型的大小），谁跑分更高（计算，推理编程），谁写代码更厉害，现在是谁真正把ai落地在企业业务里

企业买ai不是买api，也不是买token，企业要降本，提效，增长，风控
是一个能真正嵌入业务流程，每天被员工使用，最后能产生业务结果的系统。
fde更像是一个站在客户现场的ai工程负责人

工作内容：
- 理解客户的业务流程，越垂直越好
- 那些环节适合ai来改造
- 把企业的内部数据，系统，工具链接起来
- 搭建Agent，工作流，知识库，评测体系
- 确保这些东西在生产环境跑起来。
