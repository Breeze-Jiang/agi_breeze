## SDD 包含的文档有那些？
让大模型按需加载
- 需求文档 prd 产品经理
- proposal.md 是心智创造 头脑中这个系统应该是怎么样，满足什么样的需求表达
- design.md 怎么实现 技术机构 
- task.md 先干什么，在干什么，什么可以并行干，

三份规划完成第一次创造（工作内容） ， 代码是第二次创造（agent）
不停地迭代

vibe codign 问题在于跳过了第一次创造 （聊天窗口诱惑我们），直接进入第二次创造。sdd坚持所有地伟大事务都要经过两次创造，sdd 是必选项，是主要工作内容。

- sdd 框架 Spec-kit 是一个规范驱动开发的框架，帮助我们快速构建出符合规范的代码。
当代码生成成本越来越低，真正稀缺的是清晰、可执行、可验证的意图，由sdd设计。
