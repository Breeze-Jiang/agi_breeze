# 蒸馏

- 什么是蒸馏
小模型公司怎么去学习大模型的本事
2025年，deepseek 花了600万美金训练成本，做出了一个可以和openai 可以掰手腕的模型
openai 指控deepseek 用了一个叫蒸馏的技术，把openai 的输出，拿去训练自己的模型，是抄捷径

巨量的向openai 发请求

## 何为蒸馏

化学术语
把混合液体加热，让某些部分变成蒸汽挥发，然后再去冷却收集，取其精华，去其糟粕

大模型蒸馏的核心思想一样
就是把llm里的精华知识，提取出来，灌进小模型
大模型叫老师模型
小模型叫学生模型
提取的过程叫做知识蒸馏
- 向大模型发送请求 得到答案
题目和标准答案， 背答案
比如，记住 这个图就是猫，对或错
模型死记答案，这个叫**硬标签**

不够的

小模型学的是答案，而是思维方式 
大模型再回答问题时，其实不是一个答案，他给的是一组概率分布

软标签 不是一个答案 他是一个概率分布

软标签比硬标签更有信息量，它包含llm对这道题的理解方式

答案不只是只猫那么简单，而是猫和狗有相似之处，猫和老虎比较像，但是没有和狗那么像，这种软标签类比的感觉，
就是软标签

那蒸馏就是让小模型去模仿这一套的概率分布，而不只是背标准答案，而是思维答案

打个比方，我们要培养一个厨师信任，
第一种方案 ，给他菜谱 硬标签 新人只学会了菜谱步骤，没学到别的
第二种方法，让米其林厨师亲自示范，新人再旁边看，大厨怎么去判断火候，怎么去凭感觉调味，这个就是蒸馏训练
