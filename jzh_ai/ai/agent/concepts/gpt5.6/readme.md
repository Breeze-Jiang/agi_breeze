# gpt5.6
 发布后，讨论很快集中到几个问题上。

 - 跑分涨了多少？
   代码能力有没有超过claude,gemini 谁又成了最强模型
   benchmark的得分

   这些很重要，但更在意另一件事
   - openai 不在把ai 当作一个当以的聊天模型了，而是把他做成一套能够去按照任务难度 按照响应速度和成本来分配的工作系统。
    
   gpt5.6 分成 sol terra luna三个层级 有着相对固定的能力挡位。
   - sol 负责最难的任务
   - terra 负责日常工作
   - luna 更快更便宜，适合高频调用。
   看过去是一套命名，实则是改变用户的选择方式。

   - 传统用AI 往往只问一句哪个强？
   这个事情值得最强的模型吗？
  
  - 把一万条用户反馈 没做成分类或者从合同李米娜 ，去固定字段。
    Luna | Terra 根本不需要用到最强推理。
  - 写一份常规的，文档初稿 ，普通代码，整理数据，均衡模型就够了。
  - 只有碰到多分材料交叉去分析，问题本身还不清楚，或者反复调用工具和检查结果的任务，值得用sol这样的最强模型。

  以后团队拉开差距的，不是谁一直在用最强的，最贵的模型了，谁知道该把上面任务，分给什么模型。

  AI 开始去参与流程，而不只是回答问题了

  GPT5.6 还有一个更大的变化是工具写作能力更强了。
  “可编程工具的调用”，模型不再只是去调用一个工具，那带一次结果，在等待人去决定下一步
  它可以再中间去写一些轻量的程序,过滤无关的数据，整理中间的结果 ，再接着推进任务。

  GPT5.6 标志着AGI 的到来，前夕？ 
  这个会改变ai的使用方式 ，比如那行业研究来说，最费时间的通常不是去写结论（），改变ai的使用方式 ，比如那行业研究来说，最费时间的通常不是去写结论（回答），而是前面的过程，去找资料，去判断来源靠不靠谱，去整理表格，去发现信息矛盾再去补差。最后才是搭结构和写初稿

  过去的ai更像是一个顾问，你问一步，它答一步 。现在的方向是，让ai去拆任务，会调用工具，能够去检查过程的协作者（react）

  能自己调用工具和可以放心运行是两回事

  真正值得关注的是总成本，用更少的token，更少的工具调用 完成质量更高的任务

  AI 实际成本 = llm API Token 账单 + 多轮会话的反复提示词 + 工具失败后的返工 + 人工检查的时间 + 一条工作流稳定跑完的时间

  gpt 5.6 关注的不是更聪明，而是试图把复杂任务的交付成本给降下来

  GPT5.6 强调 代码 浏览， 计算机操作 ，文档， 表格， 演示

  跑分是门槛， 也不等于生产力。
  gpt 5.6 除了智能之外，还在这些能力（代码 浏览， 计算机操作 ，文档， 表格， 演示）上参与到了工作流程中，更自动化，开销更少

  大家比的不再只是模型聪明， 而是谁能够把它用进具体任务，并把结果控制住，成本好核算，

  不同的模型， 不同层次的，将会以你的虚拟员工的方式协作， 你将是带一个团队。
