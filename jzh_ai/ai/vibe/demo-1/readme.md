# 轻松上手vibe Coding

想去用ai写代码，但ai生成的要不是“幻觉代码”，看起来像那么回事，一跑就报错。

这个指南，不是怎么写代码，而是叫我们去与ai 协作写出靠谱的代码

- 新手 自然语言编程
- 不要着急写代码 先思考规划 md 文件
  每次prompt 都会自动带上规划， 保持一致性， 有整体的约束

##  操作的核心方法
- 第一步 ：规划就是一切
不要上来就让AI 去写代码，先强制它去读懂你的技术栈和项目规划。（/init ）
就好像你不会让新来的员工直接干活，去阿里入职 会先拿到阿里java 员工手册 等，等让它熟悉公司业务流程一样， ai 生产代码逻辑清晰多了
新手把codex ， cc 工具， 
老手把他们当同事，助手

背后逻辑

先划定边界 ；防止ai 擅自多加功能
强制模块拆分，（好读好维护，ai生成的代码都要审核）
引导ai复用独立组件，预先规定数据结构，从根源减少
ai参数，字段幻觉（title，不能是text，字段不能让ai 做主）
先生成规划，审核规划，更新规划
这份规划将伴随我们的项目开发完整周期

第二步：胶水编程思维
能抄不写（github 经典，优质，经过验证的代码），能连不造（a，b，c组件 胶水）。指挥ai 去找那些已经被验证过千万次的成熟组件，拼乐高一样，把它组装起来
胶水，比喻 ， 可以粘合， 少量（ai 生成的代码） 产生幻觉的可能性大大降低

胶水本身不创造零件，只负责把现成文件黏在一起，你只负责写衔接，调用，流转的粘合代码，把各个模块联通

轮子别人造好，你只做胶水，胶水不生产零件，只联通零件
