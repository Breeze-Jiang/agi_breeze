## 购买服务器
轻量云服务器  linux
全量的使用linux 部署， 命令行成本有点高， 难度高
宝塔（BT Panel）
这是一个可视化的，点击操作，完成服务器的部署
相当于给服务器安装了 一个”控制台/操作系统的界面“
得到了一个公网IP

## 宝塔的优势
/www/wwwroot
服务器内置了宝塔服务:8888 端口 （可以不用命令行）
- 可视化
- 自由度高
  想怎么部署就怎么部署

## 用户访问网站到底发生了什么？
- 浏览器输入 域名
- DNS 解析 将域名转换为IP地址   
  浏览器
  ↓
  本机 DNS 缓存
  ↓
  递归 DNS 服务器
  ↓
  根域名服务器
  ↓
  .com 顶级域名服务器
  ↓
  example.com 权威 DNS 服务器
  ↓
  返回 api.example.com 的 IP  
- 安全组/防火墙
  看门人， 放不放行
  - ip 限流， 恶意ip
  80 端口 是http 的默认端口
  443 端口 是https 的默认端口
  3306 Mysql 可选择的访问
  只开发给一些dev，production

  安全组
    位置：云厂商网络层（比如腾讯云）
    作用？控制这台云服务器哪些端口被外网访问
    类比：小区大门保安 不让进，小区里的
  防火墙
    位置：服务器操作系统内部
    类比：门
    
- Nginx : 真正的入口（分流）
  - 静态资源
    react + ts 打包
    static route ， 返回静态资源
  - 动态资源
    route 走服务器路由
  Nginx 是一个高性能的Web服务器
  三件事：接受请求，返回静态文件，或把请求转发给后端。
