# Next.js 中文 About 页面设计

## 目标

新增一个简洁的中文 About 页面，用于向访问者介绍 Next.js 的定位、核心能力和常见使用场景。页面通过独立路由 `/about` 访问，不改变现有首页的主体内容。

## 页面结构

1. **页面头部**
   - 展示 Next.js 品牌文字标识。
   - 提供返回首页的链接。

2. **Hero 区域**
   - 标题：关于 Next.js。
   - 用一段简洁文案说明 Next.js 是基于 React 的全栈 Web 开发框架。

3. **核心能力区域**
   - 使用卡片展示四项能力：文件系统路由、服务端渲染、静态生成、Server Components。
   - 每张卡片包含标题和面向初学者的简短说明。

4. **适用场景区域**
   - 介绍企业官网、博客、电商平台和全栈应用等场景。

5. **页尾行动区域**
   - 提供返回首页按钮。
   - 提供指向 Next.js 官方文档的外部链接，新窗口打开并带有安全 rel 属性。

## 视觉与响应式

- 延续项目当前的 Tailwind CSS 方案，不添加第三方依赖。
- 使用白色背景、深色文字、浅灰边框和适度圆角，保持简洁清晰。
- 内容区域使用居中的最大宽度，桌面端采用多列卡片布局，小屏幕自动堆叠为单列。
- 使用现有 Geist 字体变量和项目已有的颜色 token。
- 交互元素提供 hover 状态，并保持足够的文字与背景对比度。

## 技术实现

- 新增 `app/about/page.tsx`，使用 App Router 的静态 Server Component 页面。
- 页面内容直接写在组件中，无需数据请求、客户端状态或新增 API。
- 页面链接使用普通锚点链接；外部文档链接设置 `target="_blank"` 和 `rel="noopener noreferrer"`。
- 如需页面专属元数据，在 About 页面导出 `metadata`；否则沿用根布局元数据并同步将根布局语言设为中文、站点描述更新为 Next.js 介绍。

## 验收标准

- 访问 `/about` 能正常渲染中文 About 页面。
- 页面包含 Next.js 简介、核心能力、适用场景和官方文档入口。
- 桌面端卡片布局清晰，小屏幕无横向溢出且内容顺序合理。
- 现有 `/` 首页仍可正常访问。
- 项目 TypeScript 和 Next.js 构建检查通过。
