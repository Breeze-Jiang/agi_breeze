# 404 页面设计

## 目标

为全站未匹配路由提供中文 404 页面，并与现有 About 页面保持一致的黑白极简视觉。

## 技术方案

- 新增根级 `app/not-found.tsx`，使用 Next.js App Router 稳定的 `not-found` 文件约定。
- 页面为静态 Server Component，不使用客户端状态、数据请求或新增依赖。
- 根级页面负责处理用户访问的所有未匹配 URL，并复用现有根布局、字体和全局样式。

## 页面结构

1. 顶部导航展示 `NEXT.JS` 品牌文字和 `ERROR / 404` 状态标识。
2. 主体展示超大号 `404` 数字，作为页面视觉焦点。
3. 中文标题为“页面走丢了”，说明访问页面不存在、已被移动或地址有误。
4. 提供“返回首页”主按钮，链接到 `/`。
5. 提供“了解 Next.js”次按钮，链接到 `/about`。

## 视觉与响应式

- 使用白色背景、深色文字、浅灰细边框，并支持现有深色模式。
- 复用 About 页使用的 Zinc 色系、圆形按钮和 hover/focus 状态。
- 页面至少铺满视口高度，主体内容在可用区域内居中。
- 大号 `404` 字体在移动端缩小，按钮在窄屏纵向排列，避免横向溢出。

## 验收标准

- 访问任意不存在的路径时显示自定义 404 页面。
- 页面包含 `404`、中文错误说明、返回首页和 About 页面入口。
- `/` 与 `/about` 链接均可正常导航。
- 页面在移动端和桌面端均无横向溢出。
- Next.js 生产构建和 TypeScript 检查通过。
