# 404 页面实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 创建一个处理全站未匹配路由的中文 404 页面。

**Architecture:** 使用 Next.js App Router 根级 `app/not-found.tsx` 文件约定，实现无客户端状态的静态 Server Component。页面复用根布局和 Tailwind 全局样式，并通过 `next/link` 提供首页与 About 页面导航。

**Tech Stack:** Next.js 16.3.1、React 19.2.8、TypeScript、Tailwind CSS 4

## Global Constraints

- 新增根级 `app/not-found.tsx`。
- 页面文案使用中文。
- 不新增第三方依赖。
- 页面为静态 Server Component。
- 页面支持移动端、桌面端和现有深色模式。

---

### Task 1: 创建全站 404 页面

**Files:**
- Create: `app/not-found.tsx`

**Interfaces:**
- Consumes: `next/link` 的 `Link` 组件、根布局和项目现有 Tailwind CSS 工具类。
- Produces: 默认导出的 `NotFound()` Server Component，由 App Router 在未匹配 URL 时渲染。
