# js 有多少种数据类型
八种数据类型
根据ECMA262 规范
primitive 原始数据类型有6种，其中numeric 再可分为number 和 bigint，还有一种对象
## 简单数据类型
原始数据类型（primitive type）
- Number 数值
- String 字符串
- Boolean 布尔值
- Null 空值
  - 用于表示一个有意设置为空的对象引用（空的引用）
  - 表示某处应该有个值，但是目前没有（空的值）
  - 可以用于清空一个变量的值，释放内存，垃圾回收
- Undefined 未定义值
  表示一个未初始化 或不存在的变量值
  - 当声明一个变量但没有赋值时，默认值为undefined
  - 某个对象属性不存在
  - 函数没有返回值
  访问不存在的数组索引
es6以前，js只有6种数据类型
## es6 新增的数据类型
- Symbol 唯一
- BigInt 大整数

## 复杂数据类型
引用数据类型（内存分配）
- Object 对象
- Array 数组
- RegExp 正则表达式
- Function 函数
- Date 日期
- Math 数学对象
## 内存分配去思考
- 冯诺依曼
  运算器 储存器 输入输出，cpu，内存
- 代码 外存 硬盘
- 编译，代码从硬盘调入内存中
- 执行上下文 变量环境，词法环境，执行代码
- 推入调用栈 就在栈内存中
  快，空间小，
  变量环境/词法环境 原始数据类型，写入值
  引用数据类型，也在栈内存中，存的是对象的地址
  编译阶段给他的空间正好合适 函数执行上下文对象占用多少
  内存空间是算的出来的，当一个函数执行完，出栈，很快的算出新的栈顶元素
  指针偏移量就可以切换上下文执行
  快速，稳定 ，扩展
