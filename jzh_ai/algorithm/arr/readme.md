## 数组的创建

- ADT 的认识
  连续的存储空间 + 特定的操作
- push,pop,shift,unshift
  修改原数组 破坏了原来的数组，以下方法都不是纯函数 
  - push 返回结果是新长度
  - pop 移除的是数组最后一个元素，返回该元素
  - shift 移除的是数组第一个元素，返回该元素
  - unshift 在数组开头添加元素，返回新长度
- 纯函数是指
  - 不修改原数组
  - 只依赖于输入参数
  - 不依赖于外部状态
  - 不依赖于时间
- new Array(5)
  指定了长度的空数组
  [empty * 5] 初始化为空
  empty 表示数组的这个位置还没有被赋值
  不属于任何类型
  arr[0] 是 undefined
- (new Array(5)).fill(8)
  创建了一个长度确定，同时每个元素也确定的值的数组

## 遍历的方法
- for 循环
  机器化，命令式，缺点是可读性不好
  优点是性能最好
- for of 循环
  语义化很好
- forEach 方法
  入调用栈 执行上下文。。。
  优点是功能强大
  缺点是不能中途break;
- map，filter，every，some 方法
  基于forEach方法
  返回全新的数组 纯函数
  filter 筛选 函数结果为true则留下
  every 每一项满足
