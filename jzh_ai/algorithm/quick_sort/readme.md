# 快速排序

数组排序
- 冒泡 两两相邻位置 比较 交换‘
- 选择排序 从数组中选择最小的元素 放到数组的开头
- 插入排序  有序数组 插入元素 从后往前比较 交换
O(n^2)

## 快排 O(nlogn)
- pivot 基准值，一轮排序后 放到正确的位置
- 比他小的 放到左边
- 比他大的 放到右边
双指针交换

- 递归 对左边和右边的数组分别再做

快排（quick sort） 是一种基**分治策略**的排序算法，运行高效（O(nlogn)） （平均情况），应用广泛
分而治之

## 递归，分治的区别
递归是代码实现方式（函数自己调用自己）
自顶向下 缩小问题的规模
分治是一种算法思想，绝大多数用递归实现
分 + 治 + 合 三步
分 将大问题切成互相独立的小问题
治 解决小问题
合 合并小问题的结果

左边pivot右边

相等元素相对位置颠倒，完美体现了快排的不稳定
