## 链表
- 数组增加元素，arr.length => capacity 扩容和初始化时有内存分配的开销，其余时刻没有
- 链表 每次都申请 平均的
数据规模
小 就用数组
大 就用链表
数组的优势是 遍历 按索引取元素，缺点是增删需要移动位置和申请空间
链表的优势是 增删（找到前驱节点，不要坐过站），缺点是找到相应节点
链表和数组是相似的，他们都是有序列表（list） 都是线性结构（有且仅有一个前驱节点，有且仅有一个后继节点）
array 索引

linked list head -> node ...... -> tail
 
链表中，数据单位 节点 指针
节点和节点的分布是不连续的，是离散的
js 用对象字面量
{
  val: 1,
  next: {
    val: 2,
    next: null
  }
}
为什么要有head节点
访问链表中的任何一个元素，从起始节点开始（val 空），逐个访问next，直到找到目标节点为止，tail节点 （next 为空）

- js数组特性

如果类型不同，一段非连续内存，js数组不在具有数组的特征

链表有着高效的增删操作
