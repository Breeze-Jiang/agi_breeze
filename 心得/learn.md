### 🎮 第三阶段：高效刷题法
刷题技巧 ：

记录模板 ：

```
// 自己的解题模板
/** 
 * 题目：反转链表
 * 思路：迭代，三个指针
 * 时间复杂度：O(n)
 * 空间复杂度：O(1)
 */
function reverseList(head) {
    let prev = null;
    let curr = head;
    while (curr) {
        let next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
```

### 💡 学习建议
- 不要死记硬背 ：理解思想比背代码重要
- 不要只看不写 ：手写代码才能真正掌握
- 不要贪多求快 ：一天吃透 1 道题 > 一天刷 10 道题
- 不要害怕困难 ：medium 做不出来正常，坚持就行
